StudyLink Portal, Offline Backup

Offline survey generator

Turns a REDCap Data Dictionary into a single HTML file your team can fill in without REDCap, for when the server is unreachable. Runs entirely in your browser.

1Data DictionaryRequired

In REDCap: Project Setup → Data Dictionary → Download the current instrument(s) as CSV. This drives field types, choices, and branching logic.

2Project XMLOptional

In REDCap: Other Functionalities → "Backup Project", or the XML export under Project Setup. Add this if your project uses Events/Arms, to group forms by event and pick up the project's real title. Skip it for a single-arm project with no events.
Drop the Project XML here
or click to browse, optional

3Generate

Events, the project title, and repeat/DAG columns are all read from the Project XML if you added one. Without it, this generates a non-longitudinal survey titled "Offline Survey".

Using the generated file

  • Save the downloaded .html file somewhere every study staff member can reach: shared drive, USB, each laptop.
  • Open it in any browser. Click "+ New record" to start a participant, then click through forms with Prev/Next.
  • Answers autosave to the browser automatically. Click "Enable file autosave" once to also mirror a JSON backup to a file on disk (Chrome/Edge only); that choice is remembered on reload.
  • "Export CSV" downloads captured data in REDCap's Data Import Tool layout, ready to re-import. "Backup JSON" / "Restore JSON" round-trip the full data, e.g. to move between computers.
  • Branching logic, checkboxes, matrix question groups, required markers and sliders are reproduced from the dictionary. Calculated fields show a CALCULATED pill with the formula available in a dropdown; hidden fields show a HIDDEN pill. File uploads become a filename/description note.
Runs entirely in your browser. No data is uploaded anywhere by this generator or the files it produces.
